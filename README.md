RaceDay is a full-stack web-based event management system designed for the South African road running, walking, and cycling community. The platform addresses the gap left by paper-based registration and disconnected spreadsheets by giving event organisers a single system to create and manage events, categories, and participant results, while participants can browse upcoming events, enter races, track their personal performance history, and prepare for race day using live weather and route information. The system supports two user roles: Organisers, who can create and manage events, define race categories, and capture results; and Participants, who can browse events, enroll in categories, and view their own enrolment and results history. This repository contains the Part 1 planning deliverables for the project — the Entity Relationship Diagram, the API endpoint plan, and the SQL database script
